Why make Gmail Recipient Preview?

A message written on a wide desktop can feel fragmented on a phone. Dark Mode and pasted formatting add more uncertainty, but checking with developer tools or sending test emails is too much friction for everyday Gmail users.

Recipient context: compare wrapping and reading rhythm against common logical viewports.

Live editing: keep writing while the preview updates beside the draft.

Local processing: draft content is never uploaded, stored, or sent to an external API.

Features

Live recipient view

Subject, body, formatting, and inline images update without reopening Preview.

Mobile and Desktop

Compare a common phone viewport with a representative Gmail Web reading surface.

Light and Dark Mode

Review contrast and color behavior using an honest approximation of common themes.

Floating preview

Collapse the controls into a draggable phone and keep the draft fully editable.

Formatting checks

Flag faint, hidden, tiny, oversized, or awkwardly wrapping content locally.

Bilingual interface

Switch immediately between English and Traditional Chinese.

Reference devices

Presets are reference viewports for comparing layout—not physical-size replicas or pixel-identical native Gmail renders.

Private by design

Your selected draft is processed in the active Gmail tab. There is no backend, analytics SDK, account system, or external AI API.

Manual installation

  1. 1

    Open Chrome Extensions

    Visit chrome://extensions and enable Developer mode.

  2. 2

    Load the Extension

    Select Load unpacked and choose the Gmail Recipient Preview folder.

  3. 3

    Refresh Gmail

    Open a draft and select Preview beside the discard button.
