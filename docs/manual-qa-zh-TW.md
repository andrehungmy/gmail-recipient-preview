# Gmail 收件者預覽｜手動測試清單

這份清單是給自己晚點直接照著測的版本，不需要開發背景。請使用測試文字，不要放真實客戶、公司或私人信件內容。

## 測試前準備

- [V] 開啟 `chrome://extensions`
- [V] 確認已開啟「開發人員模式」
- [V] 找到 Gmail Recipient Preview，點選「重新載入」
  -- Current Version: 0.8.3 (2026-07-28)
- [ ] 重新整理 Gmail 分頁
- [ ] 確認 Chrome 縮放比例為 100%
- [ ] 記下目前環境：
  - 日期：2026-07-27
  - Chrome 版本：50.0.7871.129 (正式版本) (arm64)
  - macOS 版本：26.5.2
  - Gmail 顯示語言：Traditional Chinese
  - Extension 版本：0.8.3

## 測試用信件內容

主旨：

```text
下週專案進度與後續安排
```

內文：

```text
Hi Maya，

謝謝你今天撥空討論。以下是我們確認的下一步：

1. 我會在週二前提供第一版文件。
2. 你們會在內部確認後回覆意見。

補充資料：https://example.com/this-is-a-deliberately-long-address-for-testing-mobile-line-wrapping-and-readability

這是一段混合中文與 English 的測試內容，用來確認手機畫面上的換行、標點符號與閱讀節奏是否自然。

Best,
Andre
```

實際 結果／備註：測試OK

- 補充需求，可評估 UX 體驗與必要性：

1. 標註潛在問題發生的原因位置 (e.g., 游標滑到「連續空白行可能在行動裝置上形成過大的間距」時，高光目前預覽畫面會發生此狀況的連續空白行)
2. 新增小按鈕讓 User 可以點擊「忽略」or「不再提醒」
   2.1. 點擊忽略後，忽略的相同根因位置如有異動，不再次顯示重複的問題（e.g., User 從4行空白刪掉一行、User 拉動原本過大的圖片尺寸，但仍是同一張）
   2.2. 承 2.1.，若點擊忽略而在其他位置或元件出現相同類型根因（e.g., 忽略圖片過大提示後，又在不同位置貼了一張新的圖），會再次顯示相關提示
   2.3. 若點擊「不再提醒」，相同根因在本次寄信 Session 中不會再次顯示
3. 因應2功能，補充「重設」按鈕（點擊後重置上述忽略/不再顯示設定，再次顯示信件問題）

新增功能驗收：

- [ ] 游標移到提醒、用鍵盤聚焦提醒，或點擊提醒時，預覽中對應的位置會高光；點擊後會捲動到該位置
- [ ] 點擊「忽略這一處」後，調整同一張圖片或同一段空白行時，不會再次提醒
- [ ] 在其他位置新增同類問題時，仍會顯示新的提醒
- [ ] 點擊「此草稿不再提醒」後，目前草稿中的同類問題都不再顯示；其他類型仍正常提醒
- [ ] 點擊「恢復已忽略的提醒」後，這封草稿中被忽略或靜音的問題會再次顯示
- [ ] 上述操作只改變預覽提醒，不會修改 Gmail 草稿內容或格式

## 發現問題時怎麼記

每個問題請複製以下格式：

```text
問題標題：
嚴重程度：阻止使用／明顯困擾／小問題
測試編號：
操作步驟：
實際結果：
預期結果：
是否每次都發生：
Chrome 版本：
Gmail 語言：
Extension 版本：
截圖或錄影：有／無（只能使用測試資料）
```

嚴重程度參考：

- **阻止使用：** 預覽打不開、草稿被改壞、內容外洩、Gmail 無法繼續操作。
- **明顯困擾：** 主要功能可以使用，但內容不同步、按鈕重疊、視窗無法恢復或警告明顯錯誤。
- **小問題：** 文案、間距、圖示、輕微顏色或不影響完成工作的視覺問題。
