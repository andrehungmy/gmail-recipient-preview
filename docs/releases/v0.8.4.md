# Gmail Recipient Preview 0.8.4

Version 0.8.4 adds Chrome-managed localization for Store metadata without changing extension behavior, permissions, or data handling.

## Changes

- Keep English as the default locale.
- Add Traditional Chinese metadata for the extension summary.
- Preserve the product name across both locales.
- Add a Traditional Chinese Chrome Web Store detailed description.
- Include locale files in the deterministic release package and security checks.

## Release boundary

- No permission changes.
- No new network requests, backend services, analytics, or remote code.
- The existing 0.8.3 Store screenshots and promotional assets remain accurate.
