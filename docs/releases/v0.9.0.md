# Gmail Recipient Preview 0.9.0

Version 0.9.0 makes Floating preview a remembered choice and ships the localized Store metadata prepared for 0.8.4, which was never submitted.

## Changes

- Preview reopens as a Floating preview when the user last chose Floating preview, including after a Gmail refresh ([#4](https://github.com/andrehungmy/gmail-recipient-preview/issues/4)).
- Floating preview zoom (20–100%) is remembered between previews.
- Choosing Return to full preview restores the side panel as the default.
- Automatic Floating for large or fullscreen Compose windows is unchanged and does not overwrite the remembered choice.
- Invalid stored values fall back to the existing defaults (side panel, 40% Floating zoom).
- Includes the 0.8.4 changes: Traditional Chinese Store metadata and localized extension summary.

## Release boundary

- No permission changes.
- No new network requests, backend services, analytics, or remote code.
- Two interface-preference keys are added to `chrome.storage.local`; no draft content is stored. Privacy policy and Store disclosures now list five preferences.
- Existing Store screenshots and promotional assets remain accurate.
