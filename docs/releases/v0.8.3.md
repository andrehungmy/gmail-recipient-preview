# Gmail Recipient Preview 0.8.3

Version 0.8.3 is the first Chrome Web Store release candidate.

## Candidate artifact

- File: `dist/gmail-recipient-preview-v0.8.3.zip`
- Runtime files: 18
- Size: 260.2 KiB
- SHA-256: `967aabf2c614cc4f371efa46e34228ed37a0c6e0c1a1cb4193e53aacccd5c26e`
- Automated browser environment: Google Chrome 150.0.7871.187 on macOS 26.5.2

## User-facing changes

- Keeps the Preview control attached to each supported Gmail Compose window across common resize and lifecycle changes.
- Supports a side panel and a draggable Floating preview while the Gmail draft remains editable.
- Adds collapsible reference-device and preview-size controls to preserve reading space.
- Improves preview scaling and full-panel/Floating transitions.
- Adds warning highlighting, per-instance ignore, per-draft issue muting, and warning restoration.
- Preserves safe inline raster images and replaces network-backed images with local privacy placeholders.
- Updates the English and Traditional Chinese product guide and privacy disclosure.

## Release assets

- Adds a public bilingual Privacy Policy page.
- Adds Chrome Web Store listing copy, privacy answers, reviewer instructions, screenshots, and a 440 × 280 small promo tile.
- Adds a GitHub Pages workflow for the product guide and Privacy Policy.
- Uses an explicit allowlist for the extension ZIP and excludes tests, QA fixtures, store-working assets, and development dependencies.

## Verified automatically

- Formatting, ESLint, JavaScript type checking, and static security policy
- Browser synchronization and lifecycle scenarios against the local Gmail-like harness
- Sanitization, blocked remote images, local preference boundaries, and extension CSP
- English and Traditional Chinese controls
- Multiple Compose windows, cleanup, and duplicate initialization
- Warning highlight, ignore, mute, and restore behavior

## Manual release gates

The maintainer must still run the release ZIP in a clean Chrome profile against live Gmail before Store submission. The required matrix includes new message, saved draft, reply, reply all, forward, multiple Compose windows, minimize/maximize/fullscreen/pop-out, long messages, inline images, both supported locales, and extension reload recovery.

The preview remains approximate. It does not promise pixel-identical rendering in Gmail iOS, Gmail Android, Apple Mail, Outlook, or other email clients.
